# 3D Table Constructor

**3D конфигурация стола + заказ** — интерактивный 3D-конфигуратор стола руководителя.

Это одностраничное самодостаточное приложение (HTML + JS + WebGL), которое работает прямо в браузере без сервера и сборки.

## Возможности

- Живая 3D-модель стола (Three.js), вращение / масштабирование
- Настройка размеров: ширина, глубина, высота, толщина столешницы
- Профиль трубы подстолья: 40×40 · 50×50 · 60×60 · 60×30 · 50×25 · 60×40 · 80×40
- Резьбовые ножки (M6 / M8 / M10) с регулируемым вылетом
- Дополнительные модули: экран, ящик, тумба выкатная, системный блок
- Материал столешницы/ящика/тумбы: белый · серый · дуб · венге · чёрный
- Цвет металлокаркаса: чёрный · белый · серый
- Оформление заказа по e-mail (формируется письмо со спецификацией)

## Как открыть

Скачайте `index.html` и откройте его двойным кликом в браузере — приложение запустится сразу.

## Публикация на GitHub Pages

Репозиторий настроен так, что `index.html` публикуется как статический сайт:

1. Загрузите файлы этого репозитория на GitHub.
2. В репозитории откройте **Settings → Pages**.
3. В разделе **Build and deployment → Source** выберите **Deploy from a branch**.
4. Выберите ветку `main` и папку `/ (root)`.
5. Сохраните — сайт будет доступен по адресу `https://<ваш-логин>.github.io/3d-table-constructor/`.

> Файл `_config.yml` подключает пустую тему, чтобы GitHub не обрабатывал проект как Jekyll-сайт, а отдавал `index.html` как есть.
